# Product Management System

A client-side CRUD application built with pure HTML, CSS, and JavaScript. Data persists via localStorage.

## Features
- Create, edit, and delete products
- Automatic calculation of total (price minus discount)
- Bulk creation by quantity
- Live search by title or category
- Data persistence using localStorage
- Form validation and clean UI

## Stack
- HTML5
- CSS3
- JavaScript (Vanilla)

## Getting Started
```bash
git clone https://github.com/mohamedejjoud-dev/ProductManagement.git
# Open index.html in your browser
```
